## 第二阶段：项目重构优化

### 消除状态分裂

- 移除 `currentCapsMode` / `physicalCapsLock` 分离，统一走即时物理读
- 移除 `syncPhysicalCapsLockState()` / `syncPhysicalCapsLockStatePublic()`
- 简化 `setCapsMode()` — 只做物理开关，不做软件状态跟踪
- 简化 `exitCapsMode()` — 只做物理关闭

### 性能优化

- 移除不必要的 sync 调用（每次模式变更一次物理读即可）
- 状态栏/光标颜色更新不再依赖 `getTrackedState().isCapsLock`，直接读物理状态
